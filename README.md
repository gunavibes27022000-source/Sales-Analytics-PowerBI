Sales Analytics Project

About the Project

This project is based on a Sales Analytics dataset. I built the database using MySQL, performed SQL analysis to understand sales performance, and created an interactive dashboard using Power BI.

The main goal of this project is to turn raw sales data into useful business insights.

Tools Used

- MySQL
- SQL
- Power BI
- DAX

What I Worked On

- Created a Sales Analytics database in MySQL
- Created tables and established primary key and foreign key relationships
- Inserted and managed sales data
- Used SQL queries to analyze sales performance
- Worked with joins, aggregate functions, date analysis, CASE statements, subqueries and window functions
- Created an interactive Sales Analytics Dashboard in Power BI

Dashboard

The Power BI dashboard provides an overview of sales performance, product analysis and sales trends.
